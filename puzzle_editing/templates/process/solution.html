Solution and Hints

Solution

  • Write the solution in its own Google Doc in the Puzzle Drafts folder, and put its link in the puzzle’s Solution box. Postprod uses it to make the solution page on the hunt site.
  • Explain the full path from start to answer, including the aha moments, so a solver who got stuck can see what they missed.
  • Add an Author’s Notes section at the end if you want to share how the puzzle came about.
  • Once it’s written, set the status to Awaiting Solution and Hints Approval so your editor can review it.

Hints

  • Add canned hints on the puzzle’s page. Each hint has an order (roughly how far into the solve it applies) and keywords that help whoever answers hint requests find it quickly.
  • Write hints for the places testsolvers actually got stuck. The testsolve feedback is the best guide.
  • All hints are listed on the 🪙 Hint report (under More).
